# Lead Desk Mini

A full-stack Lead Management application built using the MERN stack.

## Features
- Lead submission form
- Admin authentication
- Admin dashboard
- View all leads
- Update lead status
- MongoDB database integration
- Responsive UI

## Tech Stack
- React (Vite)
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Render (Backend)
- Vercel (Frontend)
